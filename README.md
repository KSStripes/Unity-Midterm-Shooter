# Unity Midterm Shooter

A Unity first-person shooter project created as a midterm game development assignment.

## Overview

This project is a playable Unity FPS prototype with player movement, shooting, enemy behavior, health management, scene progression, UI feedback, and environmental interactions. It is preserved as an archive of past coursework and game development practice.

## What I Built

- First-person player controls for movement, looking, jumping, shooting, interacting, and picking up objects
- Bullet and rocket shooting strategies with pooled projectile objects
- Enemy behavior using patrol, detection, attack states, and Unity NavMesh pathfinding
- Health, damage, healing, death, and respawn systems
- Multi-level game state flow with intro, level progression, game over, and win states
- Interactive scene objects including doors, lifts, pressure pads, targets, and a companion cube
- HUD elements for health, weapon state, tutorial messages, low-health warnings, and death feedback
- Timeline-based cinematics for briefing and win sequences

## Tech Stack

- Unity `6000.2.10f1`
- C#
- Unity NavMesh
- Unity Timeline
- TextMeshPro
- Universal Render Pipeline

Archived. This project is no longer actively maintained and is preserved as part of my development history.
